# Orbis Kitchen

A focused DragonSword: Awakening cooking recipe finder built for the AI 产品（国外-热词游戏站）航海作业。

## Run locally

```bash
npm start
```

Open `http://localhost:4173`.

## Included

- Search recipes by dish or ingredient
- Filter by Grilling, Boiling, and Slice
- Choose food by combat use case
- Recorded ingredient merchant quick reference
- Responsive layout with accessible SVG icons

This is an independent fan-made guide and is not affiliated with Hound13 Inc.
